# ADK 2.0 and version-gated behavior

Read first when a user reports a behavior that "used to work", names a version, is upgrading from 1.x, or is on Java/Kotlin/TypeScript.

## What ADK 2.0 changes

> Source: https://adk.dev/2.0/

Three headline capabilities:

1. **Graph-based workflows** — "Build deterministic agent workflows with more control over how tasks are routed and executed."
2. **Dynamic workflows** — iterative loops and complex decision-based branching using code-based logic.
3. **Collaborative workflows** — "Build complex agent architectures with coordinator agents and multiple subagents working together" (this is what the chat/task/single-turn mode system in `../agents-and-workflows.md` enables).

Architecturally, the framework transitions from a **hierarchical agent executor** to a **graph-based execution engine**, where agents, tools, and functions operate as individual nodes within a workflow graph.

## Migration breakages, 1.x → 2.0

> Source: https://adk.dev/2.0/

- **Event schema** — 2.0 adds `node_info` and `output` fields to events. Custom database schemas storing sessions must accommodate the new fields or downstream validators will reject events. This is the one that bites teams running `DatabaseSessionService` against a hand-rolled schema.
- **Agent execution model** — agents now subclass `BaseNode`. Custom overrides of legacy methods like `_run_async_impl()` are **bypassed** under the new model; move that logic to the standardized callback mechanisms (see `../callbacks-and-runtime.md`).
- **Exception handling** — broad `try...except` blocks mask failures from the framework's automatic retry mechanism. Let exceptions propagate so 2.0 can retry properly.
- **Go import path** — update `google.golang.org/adk` to `google.golang.org/adk/v2`.

Also relevant: **task mode is disabled in graph-based workflows** on Python v2.0.0 (see `../agents-and-workflows.md`).

## Parallel 1.x maintenance

> Source: https://github.com/google/adk-python/releases

The 1.x line continues to receive updates alongside 2.x — v1.37.0 shipped **2026-07-30**, the same day as v2.6.0. A team not ready for graph workflows can stay on 1.x rather than being forced to migrate.
