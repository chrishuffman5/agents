# Cursor 3.11+

Read this when a user cannot find a Cursor setting where the documentation or an older guide says it lives.

## Agent Review settings relocated

> Source: https://cursor.com/docs/agent/agent-review.md

Agent Review is configured under **Cursor Settings → Agents → Agent Review**.

**In Cursor 3.11 and later, this setting relocated to Git & PRs → Pull Requests.**

When a user on a recent build reports that the Agent Review toggle is missing from Settings → Agents, send them to Git & PRs → Pull Requests rather than debugging further. Confirm their version before quoting either location.

## Scope of this file

Only the Agent Review relocation was documented as version-gated in the corpus fetched on 2026-08-05. Other behavior described in this skill is not known to be version-dependent — but the Cursor changelog (`cursor.com/changelog`) was not fetched, so absence of a version gate here is not evidence that a feature is version-stable.
