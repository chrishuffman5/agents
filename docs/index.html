Domain Expert Plugin

Domain Specialist Evaluation Dashboard

Eighteen domain-specialist agents, each aligned 1:1 with a skills library and armed with shipped diagnostic scripts. Every domain is measured by a Sonnet-driven eval harness that logs accuracy, token use, and latency — and compared against a no-tools baseline to quantify what the skills layer buys.

Agent mode

The task is delegated to the domain specialist, which navigates its skills library and cites sources. This is the shipped product path — measured for pass@1 accuracy, output tokens, and wall-clock per task.

Baseline (control)

The same tasks answered from the model's own knowledge with no agents, skills, or tools. The gap between the two is the measured value of the skills + specialist layer.

Method. Each domain has a task suite whose ground truth is quoted from the skills library. The harness runs every task as an independent headless session (up to 3 attempts), grading with deterministic matchers. pass@1 is first-attempt accuracy; solved counts success within three attempts. Baseline runs the identical tasks with tools disabled.

Data. Numbers are generated from the raw eval CSVs and the live script tree by evals/build-dashboard.py into docs/results.js. Re-run it after any eval sweep to refresh this page. Some domains show newer agent runs (larger task counts including script-retrieval checks) than the shared agent-vs-baseline sweep; the baseline bar always reflects the fair same-task comparison.
